# 나의 기록 재중심화 + 코스 수료 현황 (2026-07-19)

> 팀 학습용 "왜" 문서(팀 합의 규칙 2026-07-18). 코드는 "무엇"을, 이 문서는 **"왜"**를 남긴다.
> 관련 코드: 프론트 `src/pages/student/MyRecords.tsx`, 백엔드 `GET /courses`
> (`app/api/v1/endpoints/lectures.py: list_student_courses`), 시험은 [course-exam-design.md](course-exam-design.md).

## 1. 배경 — '게임 시절 통계 대시보드'였던 나의 기록

CatChap이 아동 캡차 → 인강 시청검증으로 전환([product-direction.md](product-direction.md))
하면서 게임화(코인·배지·오늘의퀴즈)를 은퇴시켰는데, **'나의 기록(성장 리포트)' 페이지에는
게임 시절 잔재가 남아 있었다:**
- `놀이별 실력`(놀이=게임 표현), 항목 이름이 `한글 낱말 찾기`·`숫자 놀이터`(게임 제목)
- `오늘의 퀴즈 · 습관 추세`(오늘의퀴즈는 Q 대재편으로 폐지 — stale 라벨)
- 상단 지표가 `총 학습 시간`·`푼 문제 수`(**"얼마나 봤나" = 워치볼륨**)를 전면에

시청 검증형 인강의 가치는 "얼마나 봤나"가 아니라 **"수료·이해했나"**인데
([catchap-dashboard-recommendation] 원칙: 시청 '양'이 아니라 '이해'를 전면), 이 화면은
반대로 가 있었다. 게다가 코스 수료·완벽 통과 같은 **현재 학습 루프의 성취를 모아 보여줄
곳이 없어서**, 수료 배지가 시험 흐름 안에만 갇혀 있었다.

## 2. 결정 — 성취 리포트로 재중심화

**게임 통계 대시보드 → "배움(강의)→연습(문제은행 Q)→증명(수료 시험)" 학습 루프의 성장·성취
리포트.** 사용자 결정 0719. 구체:
- 워치볼륨 막대(`최근 4주 학습량`) → **`코스 수료 현황` 카드**로 교체.
- 상단 지표 `총 학습 시간`(워치볼륨) → `수료한 코스 N개 · 완벽 M`.
- 게임 라벨 정리: `놀이별 실력`→`과목별 실력`, `오늘의 퀴즈 추세`→`오늘의 Q 추세`,
  백엔드 `student_records`의 mastery/activities 이름도 게임 제목 → **과목명**.

## 3. 코스 수료 현황 — 수료만이 아니라 '남은 것 + 해낸 것'

처음엔 '수료한 것만' 보여주는 트로피 진열장으로 만들었다가, **수료·진행 중·잠김을 다 담도록
확장**(사용자 결정 0719). 이유: 이 화면 이름이 "현황"이고, 학습자는 "내가 뭘 끝냈나"만큼
"이제 뭘 해야 하나"를 알고 싶다.

- **데이터 원천 = `GET /courses`의 `exam{}` 요약 하나**(별도 `/courses/completions`
  엔드포인트는 '수료한 것만' 주던 좁은 것이라 상위집합인 `/courses`로 통일하며 제거).
  `exam{}`: `has_exam`·`question_count`·`mastered_count`·`available`·`lectures_done/total`·
  `passed`·`perfect`·`passed_at`·`last_activity_at`.
- 화면은 이걸 세 칸으로 나눈다: **진행 중**(응시 가능·미수료) / **잠김**(강의 미완주) /
  **수료 완료**(완벽 통과=왕관, 일반 수료=seal).

## 4. ★정렬 = 실무 '행동 우선(action-first)'

**왜 이 정렬인가 — 실무 표준.** Coursera·Udemy·인프런·클래스101의 "내 학습" 대시보드는
전부 **지금 할 것을 위, 끝낸 것을 아래(또는 '완료' 별도 탭)**로 둔다. "계속 학습"이 항상
최상단이고 완료는 아카이브처럼 밑으로 내린다. 학습자의 다음 행동을 화면 맨 위에서 바로
집게 하기 위함이다. (반대로 '성취 자랑=배지/수료증 벽'은 완료를 앞세우지만, 그건 보통
프로필의 별도 코너지 학습 현황 대시보드가 아니다.)

그래서 정렬은:
- **그룹 순서: 진행 중 → 잠김 → 수료 완료.** 지금 응시 가능한 것(즉시 행동) 최상단,
  강의부터 봐야 하는 것(선행 필요) 다음, 다 끝낸 것(아카이브) 맨 아래.
- **칸 안 최신순:**
  - 진행 중 = `last_activity_at`(마지막 시험 활동) 최신순 — 최근에 손댄 시험이 위.
    한 번도 안 본 코스는 활동 시각이 없어 뒤로(nulls-last).
  - 잠김 = 완주율(`lectures_done/total`) 높은 순 — **열리기 직전(다음 할 것)**이 위.
    잠긴 코스는 시험 활동이 없어 시간 기준이 무의미하므로 '완주 근접도'로 근사.
  - 수료 완료 = `passed_at`(수료일) 최신순 — 최근 수료가 위.

**왜 `last_activity_at`를 백엔드에 추가했나:** 원래 `/courses`는 코스를 과목 가나다순으로만
정렬해, 최신 수료가 위로 오지 않았다(예: 7/19 수료한 코스가 7/15보다 아래). '진행 중'을
진짜 최신순으로 만들려면 "마지막으로 이 코스 시험을 본 시각"이 필요해서, 학생×코스의
`max(CourseExamAttempt.created_at)`를 요약에 실었다. ISO 문자열 그대로 사전식 비교하면
시간순이 된다(별도 파싱 불필요).

## 5. 스케일 — 코스가 많아져도 안 묻히게

칸마다 카드가 많아지면 좁은 카드 안 스크롤에 묻힌다(8개 심어 확인). 그래서 스크롤 대신
**칸마다 기본 4개(`COMP_CAP`) + '더 보기'로 펼치기**(강의 목록의 `VISIBLE_PER_GROUP`
패턴과 동일). 펼쳐 카드가 길어져도 옆 달력이 함께 늘지 않게 그 행만 `align-items: start`.

## 6. 다음 방향

  시험을 아직 안 시작한(강의만 본) 진행 중 코스도 최신순에 자연히 낀다(지금은 nulls-last).

  '더 보기'로 충분).
