## ✉️ 이메일(SMTP) 안내 — 현재 **미설정 (dry-run 모드)**

지금은 Gmail SMTP가 설정되어 있지 않습니다. 그래서 **이메일은 실제로 발송되지 않고**, 인증코드·재설정 링크 등 메일 내용이 **백엔드를 실행한 콘솔(검은 창)에 그대로 출력**됩니다.

- **아래 개발 계정으로 로그인할 때는 이메일 인증이 필요 없습니다** (seed에서 이미 인증 처리됨). 바로 로그인하면 됩니다.
- 이메일 코드가 필요한 경우는 **신규 회원가입 / 비밀번호 재설정** 테스트뿐입니다. 이때는 백엔드 콘솔에서 아래 형태를 찾으세요:
  ```
  ===== EMAIL DRY-RUN =====
  TO: ...
  SUBJECT: ...
  ... (여기 6자리 인증코드가 들어 있음)
  =========================
  ```
- 실제 발송을 켜려면: `catchap-backend/.env`의 `SMTP_USER` + `SMTP_APP_PASSWORD`(Gmail 앱 비밀번호)를 채우고 uvicorn 재시작. (설정법은 팀 내 공유 참고)
